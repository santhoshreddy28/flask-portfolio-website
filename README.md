# Flask Portfolio Website

## Overview

This project is a personal portfolio website developed using Flask, HTML, and CSS. The application demonstrates the fundamentals of web development using Flask, including routing, template rendering, static file management, and form handling.

The website serves as a digital portfolio showcasing personal information, skills, projects, and contact details.

---

## Features

* Responsive portfolio homepage
* About section
* Skills section
* Projects section
* Contact form
* Flask routing
* Template rendering with Jinja2
* Static CSS styling

---

## Technologies Used

* Python
* Flask
* HTML5
* CSS3
* Jinja2 Templates

## Installation

### Clone Repository

```bash
git clone https://github.com/santhoshreddy28/flask-portfolio-website.git
```

### Navigate to Project

```bash
cd flask-portfolio-website
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Application

```bash
python app.py
```
